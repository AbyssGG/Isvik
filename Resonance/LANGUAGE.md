# Language Guide

This repository uses **English as the default documentation language**.

## Policy

- `*.md` files in the project root are written in English by default.
- Chinese content lives in separate, explicitly labeled documents.
- English documentation is the canonical version for public open-source presentation.
- Chinese documentation is provided as an accessibility and collaboration layer, not as a mixed-language replacement.

## Naming Convention

When both language versions exist, use the following convention:

- English: `README.md`
- Chinese: `README.zh-CN.md`

Examples:

- `ARCHITECTURE.md` / `ARCHITECTURE.zh-CN.md`
- `ROADMAP.md` / `ROADMAP.zh-CN.md`
- `MIGRATION_FROM_NIMVOICE.md` / `MIGRATION_FROM_NIMVOICE.zh-CN.md`
- `CHANGELOG.md` / `CHANGELOG.zh-CN.md`

## Writing Rules

- Keep technical terms, symbol names, and API identifiers in their original English form.
- Do not mix Chinese paragraphs into the English primary documents.
- When content diverges, the English version is the source of truth unless explicitly stated otherwise.
- Translations should follow the meaning of the English document, not invent a separate roadmap or policy.

## Current Repository Status

- English documents are the primary public-facing documents.
- Chinese documents are maintained for the core project guides.
- If a Chinese version does not exist yet, the English version is the only authoritative version.
