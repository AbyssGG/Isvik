# 语言说明

本仓库默认使用**英文**作为文档主语言。

## 规则

- 项目根目录下的 `*.md` 默认使用英文。
- 中文内容放在单独、明确标注的中文文档中。
- 对外展示和开源发布时，英文文档是主版本。
- 中文文档是补充阅读层，不应替代英文主文档，也不应与英文正文混写。

## 命名规范

当同一份文档同时提供中英文版本时，使用以下命名规则：

- 英文：`README.md`
- 中文：`README.zh-CN.md`

示例：

- `ARCHITECTURE.md` / `ARCHITECTURE.zh-CN.md`
- `ROADMAP.md` / `ROADMAP.zh-CN.md`
- `MIGRATION_FROM_NIMVOICE.md` / `MIGRATION_FROM_NIMVOICE.zh-CN.md`
- `CHANGELOG.md` / `CHANGELOG.zh-CN.md`

## 写作约定

- 技术术语、符号名和 API 标识符保持英文原貌。
- 英文主文档里不要混入中文段落。
- 如果中英文内容出现差异，以英文版为准，除非文档里明确另有说明。
- 中文翻译应忠实表达英文原意，而不是单独发散出另一套路线图或政策。

## 当前状态

- 英文文档是当前对外公开的主文档。
- 核心项目说明已补齐对应的中文文档。
- 如果某份中文文档暂未提供，则英文版是唯一有效版本。
